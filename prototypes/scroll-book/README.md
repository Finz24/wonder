# Wonder scroll motion prototype

Throwaway study of the already selected scroll direction: closed cover, opening, two example Projects, closing contact scene. Native HTML/CSS/JavaScript, no dependencies. Open index.html directly or run `node prototypes/scroll-book/serve.mjs` from the repository root and visit http://127.0.0.1:4174.

The two AI-generated images and fictional Hebrew stories are labelled as examples. They are not Hila's work. See PROMPTS.md for exact built-in generation prompts; originals are retained in assets/.

WhatsApp buttons open a local demonstration dialog because Hila's number has not been supplied. No messages are sent. The revised seal is a generated transparent PNG with realistic pastel-red wax and a flowing W/H/O monogram. The original SVG study remains in the prototype source for reference. The scroll uses CSS material shading, not a physically simulated 3D model.
