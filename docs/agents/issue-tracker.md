# Issue tracker: GitHub

Issues and specs for this repo live as GitHub Issues in `Finz24/wonder`. Use the `gh` CLI for all operations.

## Conventions

- Create an issue with `gh issue create --title "..." --body "..."`.
- Read an issue with `gh issue view <number> --comments`.
- List issues with `gh issue list` and appropriate state/label filters.
- Comment, label, and close with the corresponding `gh issue` commands.

Infer the repository from the configured GitHub remote. PRs are not a triage request surface for this repo.

When a skill says to publish to the issue tracker, create a GitHub issue.
